# Support

- **Your server or account on cubepals.com:** write to **support@cubepals.com**. Issues here are
  for the code, and the people who can look into your account read the mailbox.
- **A bug in the code, or an idea:** [open an issue](https://github.com/cubepals/cubepals/issues/new/choose).
- **A security problem:** report it privately, as [SECURITY.md](SECURITY.md) says.
- **Running it yourself:** start with [docs/local-development.md](docs/local-development.md).
